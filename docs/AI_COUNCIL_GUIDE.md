# AI 합의체 — GPT · Claude · Gemini 자동 토론

PR 코멘트에 **`/ai-debate`** 한 줄을 치면, 세 모델이 그 PR의 diff를 직접
읽고 2라운드 토론한 결과를 같은 PR에 코멘트로 올립니다. 사람이 복사·
붙여넣기 하지 않습니다.

```
PR 코멘트에  /ai-debate     또는  PR에 라벨  ai-review
          ↓
GitHub Actions 가 diff 를 모은다 (PR 코드는 체크아웃하지 않는다)
          ↓
1라운드  세 자리가 각자 역할로 독립 검토
2라운드  각자 남의 1라운드 의견을 읽고 동의 / 반박 / 둘 다 놓친 것
          ↓
보고서를 그 PR 코멘트로
```

---

## 1. 준비 — 저장소 Secrets 3개

`Settings → Secrets and variables → Actions → New repository secret`

| 이름 | 발급처 |
|---|---|
| `OPENAI_API_KEY` | OpenAI Platform |
| `ANTHROPIC_API_KEY` | Anthropic Console |
| `GEMINI_API_KEY` | Google AI Studio |

**셋이 다 없어도 됩니다.** 등록된 자리만으로 돌고, 빠진 자리는 보고서에
「키가 없어 빠진 자리」로 적힙니다. **하나도 없으면 호출을 아예 하지
않고** 어느 키가 없는지만 적습니다 — 터지지 않습니다.

> 웹 구독(Plus/Pro)과 API 요금은 **별개**입니다. Actions에서 자동으로
> 돌리려면 각 플랫폼에서 API 키를 발급해 소액 충전해 두어야 합니다.

### 모델 ID를 바꿔야 할 때

모델 이름은 플랫폼마다 바뀝니다. 기본값이 거절당하면 보고서에 그 오류와
**어느 변수를 바꾸면 되는지**가 함께 적힙니다. `Settings → Secrets and
variables → Actions → Variables` 에 넣으세요(시크릿이 아니라 변수입니다):

| 변수 | 기본값 |
|---|---|
| `AI_COUNCIL_OPENAI_MODEL` | `gpt-4o` |
| `AI_COUNCIL_ANTHROPIC_MODEL` | `claude-sonnet-4-20250514` |
| `AI_COUNCIL_GEMINI_MODEL` | `gemini-1.5-pro` |

## 2. 쓰는 법

**방법 ①** — PR 코멘트에 한 줄:

```
/ai-debate
```

**방법 ②** — PR에 라벨 `ai-review` 를 붙입니다.

몇 분 뒤 같은 PR에 「🤖 AI 합의체」 코멘트가 올라옵니다.

### 로컬에서 흐름만 확인 (요금 0원)

```bash
node scripts/ai-council.mjs --dry-run
```

`--dry-run` 은 **모델을 부르지 않습니다.** 자리 상태·라운드 상한·보고서
모양만 보여 주고, 마지막 줄에 `모델 호출 0건 · 네트워크 0건` 을 적습니다.

실제 PR의 fixture로 돌려 보려면:

```bash
gh api repos/OWNER/REPO/pulls/725       > /tmp/pr.json
gh api repos/OWNER/REPO/pulls/725/files > /tmp/files.json
# (워크플로의 'PR diff를 fixture로 모은다' 단계와 같은 모양으로 합칩니다)
node scripts/ai-council.mjs --fixture /tmp/fixture.json
```

> `npm run ai:debate` 는 **아직 없습니다.** `package.json` 을 열린 PR
> 4건(#175 · #177 · #185 · #189)이 잡고 있어 건드리지 않았습니다. 그 PR들이
> 정리되면 한 줄 추가합니다. 그때까지는 위 명령을 그대로 쓰세요.

## 3. 세 자리가 보는 것이 다릅니다

같은 질문을 셋에게 하면 세 번 같은 답이 옵니다. 각도를 갈라야 토론이
됩니다.

| 자리 | 보는 것 |
|---|---|
| **GPT** | 기획 · UI/UX · 사용자 동선과 기능 누락. 화면에 붙지 않은 기능, 막다른 길, 빠진 상태 표시 |
| **Claude** | 코드 품질 · TypeScript/Next.js · 엣지 케이스와 회귀. 경계값, null과 빈 배열의 구분, 같은 판단의 중복 |
| **Gemini** | 아키텍처 · 자동매매 리스크 · 보안·데이터 무결성. 주문·청산 경로, 모드 격리, 소유권 검사, 자격증명 누출 |

세 프롬프트에는 **이 저장소가 반복해서 다친 자리**가 함께 실립니다 —
「조회 실패를 0으로 적지 않는다」, 「MOCK/TESTNET/LIVE 를 합산하지
않는다」, 「검사기가 막으면 검사기가 옳다」 등. 이것이 없으면 세 모델이
일반적인 조언만 합니다.

## 4. 요금이 새지 않게 하는 것

| 막는 것 | 어떻게 |
|---|---|
| 커밋마다 실행 | 트리거가 `issue_comment` 의 `/ai-debate` 와 라벨뿐. `push`·`pull_request` 트리거가 **없음** |
| 무한 루프 | `github.actor != 'github-actions[bot]'` **그리고** `!endsWith(actor,'[bot]')`. 봇 코멘트로는 깨어나지 않음 |
| 라운드 증식 | `MAX_ROUNDS = 2` 가 스크립트 **상수**. 인자·환경변수로 못 늘림 |
| 긴 diff | 파일 40개 · 60,000바이트 상한. 넘으면 자르고 **자른 사실과 파일 이름을 본문에 적음** |
| 출력 폭증 | 모델당 `max_tokens` 1,600 |
| 중복 실행 | `concurrency` 로 같은 PR의 앞 실행을 취소 |
| 혼자 반박 | 1라운드에서 본문을 받은 자리가 **2개 미만이면 2라운드를 돌지 않음** |

호출 횟수는 **자리 수 × 라운드 수**입니다. 셋 다 있으면 최대 6회입니다.
시험이 그 숫자를 실제로 셉니다(`scripts/test-ai-council.mjs`) — 상수가
적혀 있다는 것만으로는 증명이 아니기 때문입니다.

## 5. 이 워크플로가 **가질 수 없는 것**

```yaml
permissions:
  contents: read        # 푸시·머지·릴리스 불가
  pull-requests: read   # 읽기만
  issues: write         # 쓰기는 코멘트 한 곳뿐
```

- **머지·배포·실거래 주문을 하지 않습니다.** 할 수단이 토큰에 없습니다.
- **PR 코드를 체크아웃하지 않습니다.** diff만 API로 받아 읽습니다. PR이
  스크립트나 워크플로를 바꿔 시크릿에 손대는 길이 없습니다.
- `issue_comment` 로 깨어난 워크플로는 **base 브랜치의 워크플로 파일**로
  돕니다 — 같은 이유로 PR 쪽에서 이 파일을 고칠 수 없습니다.
- 모델 키는 **토론 단계에만** 주어집니다. diff를 모으는 단계와 코멘트를
  올리는 단계에는 `GITHUB_TOKEN` 만 있습니다.

금지를 문서에만 적으면 언젠가 지켜지지 않습니다. 위는 전부 **권한과
상수**로 막혀 있습니다.

---

## 6. 비밀이 새지 않게 하는 것

- 키 **값**은 어디에도 적지 않습니다. 자리 상태는 `●`/`○`(있음/없음)만
  보여 주고, 길이도 지문도 적지 않습니다.
- 모델 출력은 코멘트로 올리기 전에 한 겹 더 지웁니다(`redact`) —
  환경변수의 실제 키 값, 그리고 `sk-…` · `AIza…` · `ghp_…` · JWT 모양.
  막을 자리가 하나뿐이면 그 하나가 뚫릴 때 전부 뚫립니다.

## 7. 보고서를 읽는 법 — **"없음"과 "문제 없음"을 섞지 마세요**

보고서에 이런 줄이 있으면 그대로 읽으십시오.

| 줄 | 뜻 |
|---|---|
| `키가 없어 빠진 자리: …` | 그 자리의 의견이 **없습니다.** 문제가 없다는 뜻이 아닙니다 |
| `⚠️ 호출 실패 N건` | 그 자리는 **답하지 못했습니다.** 통과가 아닙니다 |
| `⚠️ 잘라낸 파일이 있습니다` | 그 파일에 대한 판단이 보고서에 **없습니다** |
| `토론은 1라운드에서 끝났습니다` | 반박할 상대가 없었다는 뜻입니다 |

**합의를 모델에게 다시 묻지 않습니다.** 라운드 내용을 그대로 싣고, 무엇이
갈렸는지는 사람이 봅니다 — 네 번째 모델이 「셋이 합의했다」를 적게 하면
그 문장의 근거가 사라집니다.
